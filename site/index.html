Pick two stations, see the next train

Results put upcoming trains first, in a font made to be easy to read.

  • Search handles typos

    Stations are grouped by province. Type "Gampha" and you still get Gampaha; "Pettah" finds Colombo Fort.

  • Next train up top

    Results start with the next departure and a countdown. Trains that already left stay hidden until you tap Show earlier trains.

  • Any day you like

    Check today, tomorrow or any date. After the last train tonight, tomorrow's first trains follow.

  • Every stop on the line

    Tap a train to see all its stops and times, with your part of the journey highlighted.

  • Starred routes and a widget

    Star the routes you take most. The home-screen widget shows the next three trains on your first one.

  • Nearest station

    One tap finds the closest station. The app reads your location only then, never in the background.

Install it in three steps

Train Lanka isn't on the Play Store yet, so you install the APK file directly.

  1. Download the APK

    Tap Download APK on your Android phone. It's the latest release from GitHub.

  2. Allow the install

    Open the file. If Android asks, let your browser or file manager install unknown apps.

  3. Open Train Lanka

    The timetable is already inside, so it works straight away, even offline.

To update, download the newest APK and install it over the old one. Your starred routes stay. Older versions are on the releases page.

Works without internet

The full timetable ships inside the app. Once a day it checks for a newer one and asks before using it.

No tracking

No account, no ads, no analytics. The app never sends your searches or location anywhere.
